## Technology Stack

### Backend
- **Framework**: FastAPI (Python)
- **Database**: PostgreSQL
- **ORM**: SQLAlchemy
- **Authentication**: JWT + Session Management
- **Logging**: Python logging with daily rotation
- **Validation**: Pydantic

### Frontend
- **Framework**: Next.js 14 (React 18)
- **Language**: TypeScript
- **Styling**: CSS Modules + Ant Design
- **HTTP Client**: Axios
